# 页面文档

本节详细介绍应用的各个功能页面。

## 页面列表

| 页面 | 路径 | 功能描述 |
|------|------|----------|
| 运动查看器 | `/motion` | 加载和播放 BVH、CSV、JSON 格式的运动数据 |
| 模型查看器 | `/model` | 加载和预览 URDF、GLTF、OBJ 等模型文件 |
| 运动映射 | `/mapping` | 将运动数据映射到目标机器人模型 |
| 动作编辑器 | `/action` | 关键帧编辑和曲线调整 |
