# 动作编辑器组件

## 概述

动作编辑器组件套件提供关键帧编辑和曲线调整功能。

## 组件列表

### CurveEditorCanvas

**源文件**: `src/components/ActionEditor/CurveEditorCanvas.vue`

曲线编辑器画布，支持贝塞尔曲线编辑和关键帧可视化。

### JointControlPanel

**源文件**: `src/components/ActionEditor/JointControlPanel.vue`

关节控制面板，提供关节参数调节功能。

### BaseControlPanel

**源文件**: `src/components/ActionEditor/BaseControlPanel.vue`

基础控制面板，提供通用的控制功能。

## 功能特点

### 1. 曲线编辑

- 贝塞尔曲线可视化
- 关键帧点拖拽
- 曲线平滑处理

### 2. 关节控制

- 关节角度调节
- 关节限位设置
- 实时预览

### 3. 基础控制

- 播放控制
- 时间轴控制
- 参数保存/加载
